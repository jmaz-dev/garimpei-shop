# Ideias de Design - Garimpei Shop Landing Page

## Abordagem Selecionada: Modern Dark Elegance com Toque Lúdico

### Design Movement
**Neomorphism moderno + Playful Minimalism** - Combinando a sofisticação de interfaces escuras contemporâneas com elementos lúdicos e interativos que refletem a natureza descontraída do e-commerce social.

### Core Principles
1. **Contraste Intencional**: Fundo escuro profundo com acentos vibrantes (laranja, verde, rosa) para destacar elementos importantes
2. **Hierarquia Clara**: Tipografia estratégica com fontes distintas para criar fluxo visual natural
3. **Interatividade Suave**: Animações delicadas que respondem ao movimento do usuário sem ser intrusivas
4. **Autenticidade Social**: Design que comunica comunidade, economia e compartilhamento

### Color Philosophy
- **Background**: Preto profundo (`#0a0a0a`) - transmite sofisticação e foco
- **Primário**: Branco e tons de cinza claro para texto principal
- **Acentos**: 
  - Laranja vibrante (`#ff6b35`) - energia, promoções
  - Verde fresco (`#2ecc71`) - crescimento, economia
  - Rosa suave (`#ff6b9d`) - comunidade, conexão
- **Intenção Emocional**: Confiança (escuro), energia (laranja), crescimento (verde)

### Layout Paradigm
- **Assimétrico com Fluxo Vertical**: Seções que fluem naturalmente de cima para baixo
- **Card-Based com Espaçamento Generoso**: Cada seção como um "card" com respiro visual
- **Diagonal Dividers**: Transições suaves entre seções usando SVG dividers com ângulos
- **Sticky Header**: Navegação fixa mas discreta que aparece conforme necessário

### Signature Elements
1. **Animated Logo Badge**: Header com logo animado que responde ao scroll
2. **Emoji Decorators**: Emojis estrategicamente posicionados como elementos visuais (🏪, 💰, 🎉, 📱)
3. **Gradient Borders**: Linhas e bordas com gradientes sutis para profundidade
4. **Floating Elements**: Pequenos elementos que flutuam suavemente para criar movimento

### Interaction Philosophy
- **Hover Effects**: Botões e cards que ganham profundidade ao passar o mouse
- **Scroll Animations**: Elementos que aparecem conforme o usuário faz scroll
- **Smooth Transitions**: Todas as mudanças de estado com transições de 300-500ms
- **Feedback Visual**: Cliques e interações com feedback imediato

### Animation
- **Entrance**: Fade-in com slide-up suave (300ms) para elementos principais
- **Hover**: Scale leve (1.02-1.05) com shadow expansion para interatividade
- **Scroll**: Parallax suave e fade-in progressivo conforme o usuário desce
- **Loading**: Shimmer effects para estados de carregamento

### Typography System
- **Display Font**: `Poppins` (bold, 700) - títulos principais e branding
- **Body Font**: `Inter` (regular, 400-500) - corpo de texto
- **Accent Font**: `Playfair Display` (italic) - citações e destaques especiais
- **Hierarchy**:
  - H1: 48px (mobile: 32px), Poppins 700
  - H2: 32px (mobile: 24px), Poppins 600
  - H3: 24px (mobile: 20px), Poppins 500
  - Body: 16px (mobile: 14px), Inter 400
  - Small: 14px (mobile: 12px), Inter 400

## Estrutura de Páginas
1. **Header**: Logo animado + navegação discreta
2. **Hero Section**: Título principal com emojis, descrição curta
3. **Features Section**: 3 features principais com ícones/emojis
4. **CTA Section**: Botão principal para WhatsApp com destaque visual
5. **Footer**: Informações de contato e links sociais
